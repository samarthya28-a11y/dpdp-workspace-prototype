# DPDP workspace prototype

A single-file, clickable prototype of a DPDP (India's Digital Personal Data Protection Act) compliance workspace with three surfaces: startup, incubator and law firm.

**Status: prototype, not a product.** No backend, no login, no saved data. All data is sample data. The intake questions, roadmap text and draft documents have not been reviewed by a lawyer. The product name is provisional and under trademark review; it is editable in the UI ("Edit name").

## Run it
Open `index.html` in a browser. No build step. Fonts load from Google Fonts.

## Work on it
See `CURSOR_PROMPT.md` for the audit, fix and suggestions task.

## Ground rules
- Do not change legal wording, thresholds or disclaimers without lawyer review.
- Never add a "compliant" or "certified" claim. Approval is a named human step.
